## 1. Compliance Matrix by Legal Framework & Feature Mapping

| Regulation / Standard                   | Legal Article / Mandate                        | Platform Feature & Implementation Control                                                                                                                                                                                                       | Engineering Status       | Verification Method                                                                                                              |
| :-------------------------------------- | :--------------------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :----------------------- | :------------------------------------------------------------------------------------------------------------------------------- |
| **COPPA / Child Protection**            | 16 CFR Part 312 / GDPR Art. 8                  | **Age Gate at Signup (UC-01):** Mandatory age confirmation checkbox (`MIN_AGE` configurable, default 16). Prevents registration if false. Stores `age_confirmed`, `age_confirmed_at`, `age_policy_version`. No date of birth is collected.      | Planned (Phase 1)        | Integration test: Signup fails with 400 Bad Request if `age_confirmed: false`. Zero DOB fields in database schema.               |
| **ePrivacy / GDPR Art. 5(3)**           | Directive 2002/58/EC                           | **Strict Cookie Consent (UC-03):** Zero non-essential scripts loaded prior to affirmative consent. Cookie banner defaults to "Reject All Non-Essential". Granular toggles for Analytics. Essential cookies (session, CSRF) explicitly exempted. | Planned (Phase 1)        | Playwright test: Network inspection verifies 0 outbound requests to third-party endpoints until consent button is clicked.       |
| **GDPR / UK GDPR Art. 5(1)(c)**         | Data Minimization Principle                    | **Master Profile Design (UC-07, UC-10):** Sensitive fields (photo, age, gender, marital status, nationality) are strictly optional and disabled by default in all templates. In-app notice on discrimination risks.                             | Planned (Phase 1)        | Schema validation test: Default template renders omit sensitive fields unless explicitly toggled on by user.                     |
| **GDPR Art. 6 & 7 / Law 81/2018**       | Lawful Basis & Consent Ledger                  | **Consent Tracking (UC-03):** Immutable consent audit table (`consent_records`) recording `user_id`, `purpose`, `granted` (boolean), `policy_version`, anonymized IP subnet, and timestamp. One-click revocation supported.                     | Planned (Phase 1)        | Unit tests verifying consent record insertion upon state change and immediate cessation of associated processing.                |
| **GDPR Art. 12 & 15 / CCPA § 1798.100** | Right of Access & Data Portability             | **Self-Service Data Export (UC-04):** Download complete personal archive containing structured JSON data (`profile.json`, `resumes.json`, `consents.json`, `jobs.json`) and raw uploaded assets in a single zip archive.                        | Planned (Phase 1)        | End-to-end test verifying generated ZIP matches 100% of rows linked to `user_id`.                                                |
| **GDPR Art. 17 / CCPA § 1798.105**      | Right to Erasure ("To Be Forgotten")           | **Cascading Hard Erasure (UC-05):** Two-tier deletion. After optional 7-day grace period, automated cascading deletion removes rows from all personal tables, purges S3 files, invalidates Redis sessions, and anonymizes audit logs.           | Planned (Phase 1)        | Integration test: Inspect database and S3 after erasure completion; zero records matching user UUID remain.                      |
| **GDPR Art. 21 / EU AI Act**            | Right to Object & AI Transparency              | **AI Objection & Notice (UC-06, UC-22-25):** Prominent notice displayed before user CV or job text is transmitted to LLM API. Checkbox opt-out of all AI processing. No user data used to train foundation models (DPA guarantee).              | Planned (Phase 3)        | Contractual setting `data_logging: false` configured on LLM provider client; API tests assert rejection of AI jobs if opted out. |
| **GDPR Art. 32 / ASVS L2**              | Security of Processing & Encryption            | **Field-Level Encryption (FLE):** Application-layer AES-256-GCM encryption for phone, address, and sensitive demographic data. Encrypted at rest, decrypted only in worker RAM for authenticated owner.                                         | Planned (Phase 1)        | Cryptographic test verifying ciphertext stored in database cannot be decrypted without active KMS key.                           |
| **GDPR Art. 33 & 34**                   | 72-Hour Personal Data Breach Notice            | **Breach Response Runbook & Audit Logs:** Security incident procedures documented in `/docs/runbooks/INCIDENT_RESPONSE.md`. Tamper-evident admin audit logs (`audit_logs`) tracking anomalous access patterns.                                  | Planned (Phase 0 / 5)    | Drill simulation during Phase 5 testing audit trail generation and automated reporting templates.                                |
| **Lebanon Law 81/2018**                 | Law on Electronic Transactions & Personal Data | **Local Privacy & Commercial Safeguards:** Chapter 2 personal data safeguards: clear notice of controller identity, right to rectify and erase, explicit consent for commercial communications, and retention limit adherence.                  | Planned (Phase 1)        | Legal disclaimer page drafted with Ministry of Economy & Trade (MoET) notification requirements flagged for Lebanese counsel.    |
| **EU Directive 2011/83/EU**             | Consumer Rights & Billing Transparency         | **Upfront Pricing & One-Click Cancel (UC-27, UC-29):** Full total pricing displayed _before_ CV creation effort. Clear auto-renewal disclosures. Cancellation flow is identical complexity to signup (single click in settings).                | Planned (Phase 4)        | UI inspection test: Subscription settings page provides direct "Cancel Subscription" button with zero dark patterns or surveys.  |
| **EU AI Act (Regulation 2024/1689)**    | AI Transparency & High-Risk Profiling          | **No Candidate Ranking / Mandatory Labeling:** Platform explicitly scopes out recruiter candidate filtering, scoring, or ranking of natural persons (avoiding High-Risk Annex III classification). AI outputs clearly labeled in UI.            | Enforced by Architecture | Architecture boundary: Recruiter portal excluded. AI suggestion badges embedded in editor.                                       |
| **WCAG 2.2 Level AA**                   | Accessibility Mandates (ADA / EAA)             | **Universal Accessibility (UC-11, UC-12, UC-17):** Fully navigable via keyboard, screen-reader accessible ARIA labels on drag handles, minimum 4.5:1 text contrast, responsive reflow, complete RTL mirroring.                                  | Planned (Phase 2)        | Automated `@axe-core/playwright` CI pipeline testing 100% of screens with 0 violations.                                          |

## 3. Data Retention & Erasure Schedule

| Data Category                    | Tables / Storage Location                  | Active Retention Period                              | Post-Deletion / Expiry Behavior                                           |
| :------------------------------- | :----------------------------------------- | :--------------------------------------------------- | :------------------------------------------------------------------------ |
| **Deleted User Accounts**        | `users`, `auth_identities`, `sessions`     | Active until account deletion requested              | **Full erasure within 30 days** (hard purge across DB & storage).         |
| **Master Profile & Resumes**     | `profiles`, `experiences`, `resumes`, etc. | Active until account or resume deletion              | Hard purged within 30 days of deletion request.                           |
| **Uploaded User Media & Proofs** | S3 Object Storage (`media_assets`)         | Active while referenced by profile or resume         | Hard deleted from S3 bucket via DeleteObject within 30 days.              |
| **Exported PDF / DOCX Files**    | S3 Storage (`export_jobs`)                 | **7 Days** from generation                           | Automated S3 Bucket Lifecycle Rule: hard delete after 7 days.             |
| **Share Link Analytics**         | `link_views` (Postgres Partitioned)        | **12 Months (Country-level only)**                   | Dropped monthly by PostgreSQL partition maintenance cron. No IPs stored.  |
| **Payment & Invoicing Records**  | `payments`, `subscriptions`                | N/A during Free Beta; 7–10 Years when billing active | Retained under tax statutory obligation; user identity pseudonymized.     |
| **Security Audit Logs**          | `audit_logs`                               | **12 Months (PII-minimized)**                        | Retained for security forensics; actor identifiers scrubbed upon erasure. |
| **Database Backups**             | Encrypted WAL / Daily pg_dump              | **30 Days rolling rotation**                         | Overwritten and permanently purged after 30-day snapshot rotation.        |
